## 四、第 2 步：读懂脚本（90 分钟，这是今天最重要的一段）

用 VS Code 打开 `D:\ai-journey\week01\list_rewrite.py`（命令：`code week01/list_rewrite.py`，回车）。

不用从头到尾看懂，**只看这 6 个地方**：

| 行号附近 | 这段代码在干什么 | 白话 |
|---|---|---|
| `ROOT = Path(__file__).resolve().parents[1]` | 找到仓库根目录 | 告诉电脑"不管你在哪运行，都去 D:\ai-journey 找东西" |
| `with open(CSV_FILE, encoding="utf-8-sig")` | 读 CSV 文件 | 打开那张手写订货单。**为什么是 utf-8-sig 不是 utf-8**：文件开头藏了个肉眼看不见的标记，用错的读法第一列的列名会变成乱码 |
| `csv.DictReader(f)` | 把每行变成字典 | 把订货单每一行变成一张员工档案卡：`row["material"]` 就是这张卡上"材质"栏的值 |
| `for i, row in enumerate(data_rows, 1):` | 循环 | 从第 1 张到第 8 张，同一套动作走 8 遍 |
| `def build_prompt(row)` | 拼提示词 | 把 "原标题 + 材质 + 尺寸 + 6 条要求" 拼成一段话发给模型。**昨天缺材质就是这里没拼全** |
| `def rewrite_one(...)` | 调模型 | 真的发一次请求，拿到回复 |
| `def save_excel(results)` | 导出 Excel | 8 条结果一张张填进表格，加粗表头，调列宽 |

**为什么昨天那条输出里没有材质**：昨天喂给模型的只有 `title_cn` 一列。`size` 和 `material` 躺在 CSV 里没被读出来。今天 `build_prompt` 里三列都拼进去了——**模型不知道这条是涤麻还是羊羔绒，它怎么可能写出来？**

这就是今天最值钱的一条经验：**效果不好的时候，先看输入缺了什么，别急着改提示词。**

## 五、第 3 步：今天的真作业 —— 把 6/8 改成 8/8（120 分钟）

跑完的结果里有两条挂了。这不是坏事，**这两条就是你的第一个 badcase，也是第 5 周做 eval 的第一批素材**：

### 第 3 条（羊羔绒 / 50x50cm）

```
改写后 : Faux Fur Throw Pillow Cover 50x50cm Fuzzy Winter Sofa Cushion Case with Zipper Insert Not Included
检查   : 材质✗ 品类词✓ 长度✗(98)
```

两个问题：

1. **长度 98 字符，超了 18 个。** 模型自己加戏：写了 `Cushion Case with Zipper`，和 `Throw Pillow Cover` 重复了。
2. **材质写成 Faux Fur，我们的检查词表里没有这个词**（词表里是 Sherpa / Fleece）。**注意：Faux Fur 其实译得没错，甚至比 Sherpa 地道——所以这里是检查规则的问题，不是模型的问题。**

### 第 5 条（水晶绒 / 35x35cm）

```
改写后 : Kids Cartoon Throw Pillow Cover 35x35cm Crystal Velvet Animal Insert Not Included
检查   : 材质✓ 品类词✓ 长度✗(81)
```

**就超了 1 个字符。** 典型的边界情况。

### 你要动的两处（明确到第几行）

**改动 1：在 prompt 里把长度要求写死。** 打开 `list_rewrite.py`，找到 `build_prompt` 函数里的第 1 条要求，现在是：

```
1. 长度不超过 80 个字符
```

改成：

```
1. 长度必须严格在 80 个字符以内（含空格）。写完后自己数一遍，超了就删掉最不重要的修饰词，宁可短不要长
```

> 这是 Prompt Engineering 的第一课：**模糊的约束等于没有约束。** "不超过"对模型来说是个软建议，"写完后自己数一遍"才是硬指令。这跟你给员工下 SOP 是一回事——"大概八分满"没人执行得了对，"超过这条线就要重打"才行。

**改动 2：把 Faux Fur 加进材质词表。** 找到文件上方那段：

```python
MATERIAL_EN = {
    ...
    "羊羔绒": ["Sherpa", "Fleece"],
```

加一个词：

```python
    "羊羔绒": ["Sherpa", "Fleece", "Faux Fur"],
```

### 改完重跑

```bash
.venv/Scripts/python.exe week01/list_rewrite.py
```

**验收线：最后一行「三项检查全过」必须显示 `8/8`。**

如果还没到：**再改，再跑。** 每次调用才几分钱，这是你现在最大的优势——**试错成本几乎为零，别怕重跑。**

> 顺带记录一下体感：你改 prompt 的一句话，模型的产出就从 6/8 变 8/8。这就是"提示词工程"的全部意思，没什么神秘的。第 2 周整周都在干这个。
