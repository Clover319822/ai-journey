## 六、卡住的技术点（下次直接带过来问，别闷头查）

1. **`.gitignore` 的 `*.xlsx` 误伤产物文件** —— 密钥要挡，产物要放，用 `!` 白名单。今天还没修。
2. **模型不擅长数字符数** —— prompt 写"不超过 80 字符"它照样超（第 3 条 98 字符）。工程上必须兜底，不能只靠 prompt。
3. **eval 判"不合格"先怀疑自己的评测字典** —— 第 3 条 Faux Fur 是典型，模型译得比你字典好。这是第 5 周的核心思维。
4. **`.env` 只有 MODEL 没有 KEY 时脚本静默降级** —— 你以为在测 Claude，实际在跑 DeepSeek。跑之前看一眼打印的"供应商"那行。
5. **截断字符串要切到最后一个空格** —— `title[:80]` 会切出半个单词，用 `rsplit(' ', 1)[0]`。明天写这段时如果卡住，直接问。
