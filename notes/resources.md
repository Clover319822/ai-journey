## 第 1-2 周：Python 与 API 基础

### 主力：CS50P（哈佛 Python 课）

- 入口：https://cs50.harvard.edu/python/
- 直接进第 0 课：https://cs50.harvard.edu/python/2022/weeks/0/
- **国内可直连，不用翻墙**（已实测）
- 全英文，有完整字幕。听不懂的地方看 B 站搬运的中文翻译版
- 怎么用：**不要只看视频**。开双屏，左边视频右边 VS Code，讲一段你自己敲一遍

**第 0 课**（约 2 小时）：函数、变量、注释、字符串、参数、`return`、格式化字符串
**第 1 课**（约 3 小时）：条件判断、`if` / `elif` / `else`、`match`、循环、异常

### 备选：廖雪峰 Python 教程

- https://www.liaoxuefeng.com/wiki/1016959663602400
- 中文，适合"看完英文课还是懵"的地方回来对照
- **注意**：这个教程难度偏高，是给有其他语言基础的人看的。看不懂就跳过，别卡住

### 不要用的

- 菜鸟教程（runoob）：实测 15 秒超时打不开
- 任何让你先背语法大全的：没用。你是要做东西的人，不是要考试的人

## 卡住了怎么办

1. **先自己查 15 分钟**：把报错信息原样丢进搜索引擎或问 AI
2. **超过 4 小时就换路径**：先用现成方案跑通，原理后面补。不要死磕
3. **报错信息完整复制粘贴**给别人看，不要截半句

**记住**：报错不是失败，是信息。两个月后你能一眼看出某个报错是拼写错还是类型错，
这种直觉只能靠撞够多的错来建立。
